## เพิ่มเติมสำหรับโปรเจกต์วิเคราะห์ข้อมูล/สคริปต์

### หลักการ
- ทำซ้ำได้: สคริปต์เดียวรันตั้งแต่อ่านข้อมูล → ทำความสะอาด → วิเคราะห์ → บันทึกผล (CSV/Markdown/ภาพ) โดยไม่ต้องแก้มือ
- Python 3 + pandas เป็นค่าเริ่มต้น (เว้นแต่ brief ระบุอื่น) ใช้ไลบรารีมาตรฐานก่อน ระบุเวอร์ชันใน requirements
- path ของข้อมูลและพารามิเตอร์รับจาก argument/ตัวแปรสภาพแวดล้อม ไม่ฝังค่าในโค้ด

### ขั้นตอน
1. สรุปสคีมาที่คาดจาก brief (ชื่อคอลัมน์ ชนิด หน่วย คีย์) ถ้าไม่ครบให้ตั้งสมมติฐานและเขียนโค้ดตรวจสคีมาตอนรัน
2. ตรวจคุณภาพข้อมูลก่อนวิเคราะห์: จำนวนแถว ค่าหาย ค่าซ้ำ ค่าผิดช่วง ชนิดผิด และรายงานเป็นตาราง
3. วิเคราะห์ตามคำถามใน brief ทีละข้อ แต่ละข้อบันทึกผลเป็นไฟล์แยก
4. ทดสอบด้วย code_execution: sandbox ไม่มีไฟล์ของโปรเจกต์ ให้สร้างข้อมูลตัวอย่างสังเคราะห์ที่มีสคีมาเดียวกัน (ระบุชัดว่าเป็นตัวอย่าง) แล้วรันสคริปต์ทั้งเส้นให้ผ่าน
5. ส่งมอบ: โครงสร้างไฟล์ → สคริปต์ (กล่องโค้ดระบุชื่อไฟล์) → requirements → วิธีรันกับข้อมูลจริง → ผลจากข้อมูลตัวอย่าง (ติดป้าย "ตัวอย่าง") → ข้อจำกัดและการตีความที่ควรระวัง

### ข้อห้าม
- ห้ามแต่งผลลัพธ์หรือแสดงตัวเลขราวกับมาจากข้อมูลจริงเมื่อรันกับข้อมูลตัวอย่าง
- ห้ามเขียนโค้ดที่แก้/ลบไฟล์ข้อมูลต้นฉบับ (เขียนผลลงโฟลเดอร์ output เท่านั้น)
- ห้ามส่งข้อมูลส่วนบุคคลออกนอกเครื่อง หรือพิมพ์แถวข้อมูลจริงลงผลงาน (ใช้ค่าสรุปหรือตัวอย่างปลอม)
