# ทักษะเพิ่มเฉพาะโปรเจกต์

วางไฟล์ชื่อตามตำแหน่ง: `captain.md`, `marketer.md`, `researcher.md`, `finance.md`, `engineer.md`, `coder.md`, `reviewer.md`

- เนื้อหาจะถูก **ต่อท้าย** คู่มือทักษะกลาง (server/skills/<ตำแหน่ง>.md ของศูนย์ควบคุม)
- ถ้าอยากให้ **แทนที่** คู่มือกลางทั้งหมด ให้บรรทัดแรกของไฟล์เป็น `<!-- replace -->`
- เขียนเป็นขั้นตอน เกณฑ์คุณภาพ รูปแบบผลงาน และข้อห้ามที่เฉพาะกับโปรเจกต์นี้ (ไม่เกิน 6,000 ตัวอักษร)

ตัวอย่าง `coder.md`:

```
## เพิ่มเติมสำหรับโปรเจกต์นี้
- ใช้ TypeScript strict และ ESLint config ของโปรเจกต์
- ทุกฟังก์ชันสาธารณะต้องมี unit test ใน tests/
- ห้ามเพิ่ม dependency ใหม่โดยไม่ระบุเหตุผล
```
