# สเปกสไปรต์ตัวละคร (Ragnarok Hi-class style) — Sprite Spec

เราวาด **พิกเซลอาร์ตต้นฉบับของเราเอง** ในสไตล์เกม 2D MMO คลาสสิก (chibi หัวโต) ที่สื่อถึงอาชีพ Hi-class ของ Ragnarok
ห้ามคัดลอก/แกะสไปรต์จากไฟล์เกมจริง (ลิขสิทธิ์ Gravity Co.) — ใช้ได้เฉพาะ "ลักษณะเด่นของอาชีพ" ที่เป็นแนวคิดทั่วไป
(อัศวินใส่เกราะถือหอก, นักบวชชุดขาวทอง, จอมเวทหมวกแหลม, นักธนูถือธนู ฯลฯ)

## 1. ไฟล์และรูปแบบ (ES module)

ไฟล์ละ 1 อาชีพ: `public/sprites/<jobId>.js` — `export default { ... }` ตามโครงนี้ (ดูตัวอย่างจริงใน `public/sprites/_base.js`)

```js
export default {
  id: "sniper",              // = ชื่อไฟล์
  job: "Sniper",             // ชื่ออาชีพ RO Hi-class (อังกฤษ)
  jobTh: "สไนเปอร์",          // ชื่อไทยสั้น ๆ
  size: { w: 24, h: 32 },    // ทุกเฟรมของตัวละครต้องขนาดนี้เท่านั้น
  anchor: { x: 12, y: 31 },  // พิกเซลที่เป็น "จุดวางเท้า" (ใช้วางบนพื้น)
  palette: { k: "#1b1b1f", s: "#f3c9a4", ... },  // ตัวอักษร 1 ตัว → สี #rrggbb ; "." = โปร่งใส (ห้ามกำหนด ".")
  frames: {
    idle: [ [...32 แถว ยาว 24 ตัวอักษร...] ],        // 1–2 เฟรม (ถ้า 1 เฟรม engine จะโยกหายใจให้เอง)
    work: [ frame, frame, (frame) ],                   // 2–4 เฟรม: ท่าใช้สกิล/อาวุธประจำอาชีพ (loop)
    sit:  [ frame ],                                   // 1 เฟรม: นั่งพัก (ใช้ตอน "หยุดชั่วคราว")
  },
  // อุปกรณ์ประจำสถานีทำงาน วางอยู่ข้าง/หลังตัวละคร (เช่น หุ่นซ้อมยิง, ทั่งตีเหล็ก, โต๊ะหนังสือ, วงเวท, แท่นบูชา)
  station: { size: { w: 32, h: 24 }, anchor: { x: 16, y: 23 }, frames: [ frame, (frame) ], palette: {...เพิ่มเติมได้...} },
  // เอฟเฟกต์สกิลที่ซ้อนทับตอนทำงาน (loop พร้อม work) วาดบนตัวละคร/สถานี เช่น ลูกศรพุ่ง, ประกายไฟ, วงเวทเรืองแสง, แสงศักดิ์สิทธิ์
  effect:  { size: { w: 32, h: 32 }, anchor: { x: 16, y: 31 }, frames: [ frame, frame, frame ], palette: {...} },
};
```

กฎ:
- `frames.*` ของตัวละคร: ทุกเฟรม = array ของ **32 string** แต่ละ string ยาว **24 ตัวอักษร** พอดี
- `station` และ `effect` กำหนด `size`/`anchor` ของตัวเองได้ (แนะนำ station 32x24, effect 32x32) ทุกเฟรมใน layer เดียวกันต้องขนาดเท่ากัน
- ตัวอักษรที่ใช้ต้องมีใน `palette` (palette ของ layer ย่อยจะรวมกับ palette หลัก)
- `anchor` ของตัวละครต้องเป็นแถวล่างสุดของเท้า (ปกติ `y: 31`), `x` = กึ่งกลางลำตัว (ปกติ 12)
- ห้ามใช้ตัวอักษร "." ใน palette และห้ามเว้นวรรค
- จำนวนสีต่อตัวละคร 8–16 สี กำลังดี (สไตล์ 16-bit)

## 2. สัดส่วนและสไตล์ (ต้องสม่ำเสมอทั้งทีม)

- เริ่มจาก `_base.js` แล้ว **แก้ทรงผม/หมวก/ชุด/อาวุธ** ให้เป็นอาชีพนั้น — รักษาตำแหน่งหัว (แถว 2–15), ตา (แถว 9–11), ลำตัว (16–25), ขา (26–31)
- หัวโตประมาณ 14 พิกเซล ตาโต 2x3 พิกเซลมีไฮไลต์สีขาว 1 จุด ขาสั้น ตัวเล็ก (ดูการ์ตูน ไม่ใช่สมจริง)
- เส้นขอบสีเข้ม (`k`) รอบนอกทุกชิ้น 1 พิกเซล เพื่อให้อ่านรูปทรงได้บนพื้นหลังเข้ม
- ใช้ "แสงจากบนซ้าย": สีหลัก + สีเงา (shade) อย่างน้อย 1 ขั้นต่อวัสดุ
- **ท่า work ต้องเห็นชัดว่าต่างจาก idle** (แขน/อาวุธ/ร่างกายขยับอย่างน้อย 3–4 พิกเซล) และเฟรมใน work ต้องต่างกันจริง
- หันหน้าไปทาง "ผู้ชม" (front view) หรือหันซ้ายเล็กน้อย เหมือนสไปรต์ RO มุมกล้องเฉียง
- อาวุธ/หมวกยื่นออกนอกลำตัวได้ แต่ต้องอยู่ใน 24x32 (ถ้ายาวมาก เช่น หอก/คทา ให้ใส่ไว้ใน `effect` หรือ `station` แทน)

## 4. เฟรมพิเศษที่ engine ใช้ร่วมกัน (`public/sprites/common.js`)

```js
export default {

  items:  { size: {w:12,h:12}, frames: { scroll: [f,f], letter: [f] } },          // ม้วนงาน/จดหมายที่บินไปมาเวลา "มอบหมาย/ส่งต่อ/ส่งผลงาน"
  emotes: { size: {w:12,h:14}, frames: { alert: [f], question: [f], dots: [f,f,f], sleep: [f,f], angry: [f], heart: [f] } }, // อีโมตเหนือหัวแบบ RO
  fx:     { size: {w:32,h:32}, frames: { levelup: [f,f,f,f], bless: [f,f,f], fail: [f,f] } },  // ออร่าเลเวลอัป, แสงอวยพร (QA ผ่าน), เครื่องหมายไม่ผ่าน
};
```

## 6. Tileset เมืองมอร็อค (`morroc-ground.js`, `morroc-buildings.js`)

ฉากเป็นไอโซเมตริก กระเบื้องพื้น **32x16** (รูปสี่เหลี่ยมขนมเปียกปูน: แถวบนสุดมีพิกเซลตรงกลาง 2 จุด กว้างขึ้นทีละ 4 ต่อแถวจนเต็ม 32 ที่แถว 7–8 แล้วแคบลง) วัตถุวาง `anchor` ที่ "กึ่งกลางฐาน" ซึ่งตรงกับกึ่งกลางกระเบื้อง

```js
// morroc-ground.js
export default {
  id: "morroc-ground",
  palette: {...},
  tiles: {   // ทุก tile 32x16 ไม่ต้องมี anchor
    size: { w: 32, h: 16 },
    frames: { sand: [f], sand2: [f], sandDark: [f], stone: [f], stoneLight: [f], carpet: [f], carpetEdgeN: [f], carpetEdgeE: [f], carpetEdgeS: [f], carpetEdgeW: [f], carpetCornerNE: [f], carpetCornerNW: [f], carpetCornerSE: [f], carpetCornerSW: [f], water: [f, f] },
  },
  props: {   // ของตกแต่งเล็ก แต่ละชิ้นกำหนด size/anchor เอง
    cactus: { size: {w:16,h:24}, anchor: {x:8,y:21}, frames: [f] },
    crates: { size: {w:24,h:22}, anchor: {x:12,y:19}, frames: [f] },
    rug:    { size: {w:32,h:16}, anchor: {x:16,y:8}, frames: [f] },
    brazier:{ size: {w:16,h:28}, anchor: {x:8,y:25}, frames: [f, f] },   // ไฟ 2 เฟรม
  },
};
// morroc-buildings.js
export default {
  id: "morroc-buildings",
  palette: {...},
  props: {
    well:      { size:{w:48,h:40}, anchor:{x:24,y:34}, frames:[f] },      // บ่อน้ำ/น้ำพุกลางลาน
    wall:      { size:{w:32,h:28}, anchor:{x:16,y:24}, frames:[f] },      // กำแพงหินทราย 1 กระเบื้อง (วางต่อกันได้)
    wallCorner:{ size:{w:32,h:32}, anchor:{x:16,y:28}, frames:[f] },
    gate:      { size:{w:64,h:56}, anchor:{x:32,y:48}, frames:[f] },      // ประตูเมืองโค้ง
    palm:      { size:{w:32,h:48}, anchor:{x:16,y:45}, frames:[f, f] },   // ใบไหว 2 เฟรม
    tower:     { size:{w:48,h:80}, anchor:{x:24,y:72}, frames:[f] },      // หอเวทมนตร์ (ยอดแหลม/คริสตัล)
    domeHouse: { size:{w:64,h:64}, anchor:{x:32,y:56}, frames:[f] },      // อาคารโดม (ห้องสมุด)
    house:     { size:{w:64,h:52}, anchor:{x:32,y:44}, frames:[f] },      // บ้านหินทรายหลังคาเรียบ
    stall:     { size:{w:48,h:40}, anchor:{x:24,y:34}, frames:[f] },      // แผงตลาดผ้าใบลาย
    forge:     { size:{w:64,h:56}, anchor:{x:32,y:48}, frames:[f, f] },   // โรงตีเหล็กมีเตาไฟ 2 เฟรม
    temple:    { size:{w:64,h:64}, anchor:{x:32,y:56}, frames:[f] },      // วิหารเล็กเสาหิน
    shelf:     { size:{w:32,h:36}, anchor:{x:16,y:32}, frames:[f] },      // ชั้นม้วนกระดาษ
    pyramid:   { size:{w:96,h:64}, anchor:{x:48,y:60}, frames:[f] },      // ปิรามิดไกล ๆ (ตกแต่งนอกแผนที่)
  },
};
```

- สีหลักของมอร็อค: หินทราย `#d9b07a` / เงา `#b8884f` / เข้ม `#8a5e34`, ทราย `#e8c98a` / `#d4b06c`, หลังคา/ผ้าใบ แดงอิฐ `#a63d2f` กับ ครีม, น้ำ `#3f8fb5` / `#6cc4e0`, พรม `#8e1f2a` ขอบทอง `#e8b74a`
- กระเบื้องพื้นต้องต่อกันได้เนียน (ขอบสี่เหลี่ยมขนมเปียกปูนตรงกัน ไม่มีเส้นขอบดำรอบกระเบื้อง ใช้สีเข้มขึ้นเล็กน้อยที่ขอบล่าง-ขวาพอ) ; `sand`/`sand2` ต่างกันเล็กน้อย (จุดกรวด) เพื่อไม่ให้ซ้ำ
- อาคารเป็นไอโซเมตริก: หน้าด้านซ้ายสว่าง หน้าด้านขวามืดกว่า หลังคา/ยอดสว่างสุด มีขอบดำเฉพาะเส้นรอบนอก
- ตรวจด้วย `node tools/render-sprite.mjs public/sprites/morroc-ground.js 3` (tiles จะเรียงเป็นแถวในภาพ)

## 7. การนำไปใช้ใน engine (สำหรับคนทำ scene)

- โหลดด้วย `import("./sprites/<jobId>.js")`; ถ้าไม่มีไฟล์ให้ใช้ `_base.js`
- เรนเดอร์ทุกเฟรมลง offscreen canvas ครั้งเดียว (scale จำนวนเต็ม 2–4) แล้ว `drawImage` ด้วย `imageSmoothingEnabled=false`
- วางตัวละครที่ `anchor` บนจุดยืน; `station` วางให้ anchor ของมันอยู่จุดเดียวกับเท้าตัวละครแต่เลื่อนไปด้านหลัง/ข้างตามที่ scene กำหนด; `effect` วาง anchor ตรงเท้าตัวละคร (ซ้อนทับ)
- idle: ถ้ามีเฟรมเดียวให้โยก y ±1 พิกเซลทุก 500ms; work: สลับเฟรมทุก 180ms; sit: นิ่ง
