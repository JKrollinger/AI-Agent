# ธีม Ragnarok Hi-class + เมืองมอร็อค — ทีม AI ในร่างตัวละคร

## 1. เรื่องลิขสิทธิ์ (อ่านก่อน)

ตัวละคร ชื่ออาชีพ แผนที่ และสไปรต์ใน Ragnarok Online เป็นทรัพย์สินทางปัญญาของ Gravity Co., Ltd.
โปรเจกต์นี้ **ไม่ได้ใช้ไฟล์ภาพ/สไปรต์จากเกม** — เราวาดพิกเซลอาร์ตต้นฉบับของเราเองในสไตล์ 2D MMO คลาสสิก
โดยอิง "แนวคิดอาชีพ" ทั่วไป (อัศวิน นักบวช จอมเวท นักธนู ช่างตีเหล็ก นักปราชญ์ นักลอบเร้น) และ "บรรยากาศเมืองทะเลทราย"
ชื่ออาชีพ (Lord Knight, High Priest ฯลฯ) ใช้เป็นชื่อเล่นภายในองค์กรเท่านั้น หากจะเผยแพร่สู่สาธารณะ/เชิงพาณิชย์ ควรเปลี่ยนชื่อเป็นของตนเอง
(เช่น "อัศวินผู้บัญชาการ", "นักบวชผู้ตรวจ") หรือขอสิทธิ์จากเจ้าของ IP

**ข้อยกเว้นที่ผู้ใช้เลือกเอง (19 ต.ค. 2026):** เพื่อประหยัดโทเคนจากการวาดสไปรต์ ระบบรองรับการวาง **ไฟล์ PNG ของตัวละครจากตัวจำลอง ratemyserver.net** ไว้ที่ `public/sprites/png/<jobId>/`
(ดูวิธีตั้งชื่อไฟล์ใน `public/sprites/png/README.md`) ภาพเหล่านั้นเป็นสไปรต์จากเกมจริง จึงใช้ได้เฉพาะต้นแบบ/ภายในเท่านั้น
ถ้าจะเผยแพร่หรือใช้เชิงพาณิชย์ ให้ลบโฟลเดอร์ `png/` ออก ระบบจะกลับไปใช้สไปรต์ที่วาดเองทันที

## 3. สถานะ ↔ แอนิเมชัน (สรุปจาก docs/04)

| สถานะ/เหตุการณ์ | สิ่งที่เห็นบนแผนที่ |
|---|---|
| ว่าง | ยืนเฉยโยกตัว + ป้าย "ชื่อ · ว่าง" + กล่องแชต "พร้อมรับงาน" |
| ได้รับมอบหมาย | ม้วนกระดาษบินจากกัปตันมาหา + อีโมต "!" + cast bar ชื่องาน |
| กำลังทำ | ท่าใช้สกิลประจำอาชีพ + เอฟเฟกต์ + HP bar = ความคืบหน้า + กล่องแชตบอกเฟส |
| เสร็จ | อีโมต ♥ + จดหมายบินกลับกัปตัน |
| QA ผ่าน | แสง Blessing ลงมาจากฟ้า |
| QA ไม่ผ่าน → ส่งกลับแก้ | อีโมตโกรธที่ QA + ม้วนกระดาษบินกลับไปหาคนทำ (ป้าย 🔁) |
| ส่งต่อด้วยมือ | อีโมต "?" ที่คนส่ง + ม้วนกระดาษบินไปคนรับ |
| หยุดชั่วคราว | นั่งพัก + อีโมต zZ |
| โจทย์เสร็จทั้งหมด | "LEVEL UP!" + ออร่าทอง + อนุภาคทองที่กัปตัน |

## 5. สิ่งที่เรียนรู้จากวีดีโอตัวอย่างของผู้ใช้ (Command Center แบบออฟฟิศ)

- แผนที่ไอโซเมตริกแบ่ง "ห้อง/แผนก" มีป้ายชื่อห้องสีต่าง ๆ ตัวละครประจำโต๊ะ → ของเรา: โซนในเมืองมอร็อค ป้ายโซน ตัวละครประจำสถานี
- ป้ายลอยเหนือหัว "ชื่อ · สถานะ" (ว่าง / กำลังทำ xx% / ชื่องาน) → ป้ายสถานะ + cast bar
- แผงรายชื่อพนักงานด้านซ้าย: ชื่อ · ห้อง · สถานะ · % · "เสร็จวันนี้ N งาน" → จะเพิ่มแผงซ้ายใน app.js (หลังงาน LIVE tools เสร็จ)
- ด้านล่าง: บันทึกเหตุการณ์ตามเวลา + การ์ดงานที่มี "ใครมอบหมาย · เวลา · ขั้นตอน (จุด timeline) · %" + ปุ่ม "สั่งงานใหม่" → ปรับแท็บงาน/บันทึกให้มี timeline แบบจุด
- หน้าตั้งค่า AI: เลือกผู้ให้บริการ/โมเดลต่อพนักงาน (เช่น DeepSeek, Claude Haiku) + สถิติโทเคน/ค่าใช้จ่ายต่อคน → เพิ่ม "ตั้งค่าโมเดลต่อคน" (ต้องมี endpoint ฝั่ง server) และใช้แท็บตัวชี้วัดเดิม
- หน้าสถานะเซิร์ฟเวอร์/Uptime → ใช้ /api/health ขยายเป็นการ์ดสถานะได้ภายหลัง
