# เลย์เอาต์ dashboard ใหม่ (อิงวีดีโอตัวอย่าง) — ทำหลังงาน "LIVE tools" เสร็จ

สิ่งที่คงไว้: SSE/handlers, drawer, toast, แท็บ งาน/ตัวชี้วัด/บันทึก/ผลงาน, ปุ่มควบคุมทั้งหมด
สิ่งที่เปลี่ยน: โครงหน้าเป็น 3 คอลัมน์ + แถบงานล่าง — เวทีกลางคือฉากออฟฟิศ 3 มิติ (`public/office3d/` ใน iframe, ดู docs/09) ฉาก 2 มิติเดิมถูกถอดออกแล้ว (20 ต.ค. 2026)

```
┌ topbar: โลโก้/ชื่อ · ป้ายโหมด · ช่องสั่งงาน + ปุ่ม · KPI chips (ว่าง/กำลังทำ/คิว/เสร็จวันนี้/ต้นทุน) · ปุ่ม ⚙ ตั้งค่า AI ┐
├ roster 280px ┬ stage (ออฟฟิศ 3 มิติ — ปุ่ม ⟲ มุมกล้อง + ความเร็วจำลอง มุมขวาบน) ┬ panel 400px (แท็บเดิม) ┤

│ ▸ ริน ...    ├ task strip 170px: "งานที่สั่งวันนี้" การ์ดงานล่าสุด 5 ใบ + [+ สั่งงานใหม่] ┤                        │

```

## 1. Roster (แผงรายชื่อซ้าย) — เหมือนรายการ "ทีม AI" ในวีดีโอ

แต่ละแถว (คลิก → drawer เดิม):
- avatar อีโมจิประจำตำแหน่ง (ตัวละครจริงอยู่ในฉาก 3 มิติ)
- บรรทัด 1: **ชื่อตำแหน่ง** (สีประจำตำแหน่ง เช่น นักการตลาด) · chip สถานะ: `ว่าง` / `กำลังทำ 45%` / `หยุดพัก` / `รอรับงาน`
- บรรทัด 2 (เทา เล็ก): ตำแหน่งภาษาอังกฤษ (roleLabel) · "เสร็จวันนี้ N งาน" · "🔧 N" (toolCalls ถ้ามี)
- ถ้ากำลังทำ: ชื่องาน (ตัด 26 ตัวอักษร) + แถบ progress บาง ๆ สีประจำตำแหน่ง · คลิกแถว = เปิด drawer + กล้อง 3 มิติซูมเข้าโต๊ะคนนั้น
- hover แถว → `scene.setHover(id)` ให้ตัวละครบนแผนที่เรืองแสงด้วย
- "เสร็จวันนี้" = นับ task.status==="done" ที่ finishedAt อยู่ในวันนี้ของ agent นั้น (ฝั่ง client จาก S.tasks)

## 2. Task strip (แถบงานล่างใต้แผนที่) — การ์ดงานแบบวีดีโอ

การ์ดกว้าง ~230px เลื่อนแนวนอน แสดงงาน 5 ชิ้นล่าสุด (ทุกสถานะ) + การ์ดแรกเป็นปุ่ม "+ สั่งงานใหม่" (focus ช่องสั่งงานด้านบน)
- หัวการ์ด: avatar + ชื่อผู้รับ · "กัปตันมอบหมาย · HH:MM"
- ชื่องาน (2 บรรทัด)
- **timeline 5 จุด**: สั่งงาน → รับงาน → กำลังทำ → ตรวจ QA → เสร็จ ; จุดที่ผ่านแล้วสว่าง จุดปัจจุบันกะพริบ ; mapping จาก `task.history[].type`: created→สั่งงาน, assigned→รับงาน, started→กำลังทำ, (มี review หรือ role reviewer เสร็จ)→ตรวจ, done→เสร็จ ; failed/cancelled → จุดสุดท้ายสีแดง/เทา
- ท้ายการ์ด: % + chip สถานะ ; คลิก → drawer งาน

## 3. ตั้งค่า AI (modal จากปุ่ม ⚙) — เหมือนหน้า "ตั้งค่า AI" ในวีดีโอ

แท็บ 1 "ตั้งค่าต่อคน": ตาราง พนักงาน · ตำแหน่ง/อาชีพ · โมเดล (select: claude-opus-5-5, claude-sonnet-5-5, claude-haiku-5-5, claude-fable-5-1) · effort (low/medium/high/xhigh) · เครื่องมือ (เปิด/ปิด) · โทเคนรวม · ต้นทุนรวม · ปุ่มบันทึก
→ ต้องเพิ่ม endpoint `POST /api/agents/:id/config {model?, effort?, toolsEnabled?}` ใน server (อัปเดต agent.model/effort ใช้กับงานถัดไป; บันทึก event `agent.updated`) — ทำหลังงาน LIVE tools
แท็บ 2 "ผลงาน 7 วัน": ตาราง พนักงาน · งานเสร็จ · ล้มเหลว · ส่งต่อ · คะแนน QA เฉลี่ย · ต้นทุน — จาก `GET /api/stats?days=7` ที่อ่าน `logs/events.jsonl` (task.completed/task.failed/task.handoff/task.review) รวมต่อ agent
แท็บ 3 "คำขอตรวจสอบ": รายการผลตรวจ QA ล่าสุด (task.review events): เวลา · งาน · ผู้ทำ · คะแนน · ผ่าน/ไม่ผ่าน · feedback ย่อ

## 4. Topbar KPI chips

`ว่าง a/b` · `กำลังทำ n` · `คิว n` · `เสร็จวันนี้ n` · `ต้นทุน $x` · `โหมด` (ใช้ S.totals เดิม + นับ done วันนี้)

## 5. ขนาดจอ

- < 1280px: roster ยุบเป็นแถบ avatar แนวตั้ง 56px (ชื่อโชว์ตอน hover)
- < 1000px: ซ้อนแนวตั้ง: topbar / stage (62vh) / task strip / roster+panel เป็นแท็บเดียวกัน
