# สไปรต์ตัวละครแบบไฟล์ภาพ PNG

วางไฟล์ PNG ของแต่ละอาชีพไว้ในโฟลเดอร์นี้ ระบบจะใช้ภาพแทนสไปรต์ที่วาดในโค้ด (`public/sprites/<jobId>.js`) โดยอัตโนมัติ
อาชีพไหนไม่มีโฟลเดอร์/ไฟล์ ก็ใช้สไปรต์เดิมหรือภาพสำรองตามปกติ ไม่ต้องแก้โค้ด แค่รีเฟรชหน้าเว็บ

## โครงสร้างโฟลเดอร์และชื่อไฟล์

```
public/sprites/png/
  lord-knight/   idle.png  work.png  sit.png        ← กัปตัน
  sniper/        idle.png  work-1.png  work-2.png   ← นักวิจัย (ริน)
  stalker/       idle.png                            ← นักวิจัย (ต้น)
  high-wizard/   idle.png  ...                       ← นักวิเคราะห์
  professor/     idle.png  ...                       ← นักเขียน
  whitesmith/    idle.png  ...                       ← นักพัฒนา
  high-priest/   idle.png  ...                       ← QA
```

ชื่อโฟลเดอร์ = `jobId` ของแต่ละคนใน `server/agents.js` (`DEFAULT_TEAM[].jobId`)

| ไฟล์ | ใช้เมื่อ | บังคับ? |
|---|---|---|
| `idle.png` หรือ `idle-1.png`, `idle-2.png`, … | ยืนว่าง (ถ้ามีเฟรมเดียวจะโยกตัวขึ้นลงให้เอง) | **ต้องมี `idle`** อย่างน้อย 1 ภาพ |
| `work.png` หรือ `work-1.png`, `work-2.png`, … | กำลังทำงาน (วนเฟรมทุก 0.18 วิ) | ไม่บังคับ (ไม่มี = ใช้ idle) |
| `sit.png` หรือ `sit-1.png`, … | หยุดพัก | ไม่บังคับ (ไม่มี = ใช้ idle) |

- เฟรมแบบมีเลขเริ่มที่ `-1` และต้องเรียงต่อกันไม่ข้ามเลข (สูงสุด 8 เฟรมต่อท่า)
- เซฟจากตัวจำลองได้เลย (ภาพกรอบ 240×240 ที่ตัวละครอยู่กลาง) ระบบจะ **ตัดขอบว่างรอบตัวละครออกและย่อ/ขยายให้สูงพอดีกับตัวละครอื่นในฉากอัตโนมัติ** จุดยืน = กึ่งกลางด้านล่างของตัวละครหลังตัดขอบ
- ถ้าตัวใหญ่/เล็กไปจากที่ต้องการ ใช้ `scale` ใน manifest (เช่น 1.2 = ใหญ่ขึ้น 20%) ถ้าลอย/จมใช้ `offsetY`
- พื้นหลังสีทึบจะถูกทำให้โปร่งใสอัตโนมัติ (ใช้สีที่มุมซ้ายบนของภาพเป็นสีพื้น) ถ้าภาพมีพื้นโปร่งใสอยู่แล้วจะไม่แตะ
- ภาพทุกเฟรมของท่าเดียวกันควรเซฟจากตัวจำลองด้วยการตั้งค่าเดียวกัน (ทิศ/ซูม) ไม่งั้นขนาดจะกระโดดเวลาสลับเฟรม

## manifest.json (ไม่บังคับ) — ปรับขนาด/ตำแหน่ง/ชื่อไฟล์เอง

วางไว้ในโฟลเดอร์ของอาชีพนั้น เช่น `public/sprites/png/sniper/manifest.json`

```json
{
  "scale": 1.2,
  "offsetY": -2,
  "transparent": "#ffffff",
  "anims": {
    "idle": ["stand.png"],
    "work": ["attack_1.png", "attack_2.png", "attack_3.png"],
    "sit": ["sit.png"]
  }
}
```

| ฟิลด์ | ความหมาย | ค่าเริ่มต้น |
|---|---|---|
| `scale` | ตัวคูณขนาดเพิ่มจากขนาดอัตโนมัติ (1 = สูงเท่าตัวละครอื่นในฉาก, 1.2 = ใหญ่ขึ้น 20%) | `1` |
| `offsetY` | เลื่อนภาพขึ้น/ลงเป็นพิกเซล (ลบ = ขึ้น) | `0` |
| `transparent` | `"auto"` = สีมุมซ้ายบน, `"#rrggbb"` = สีที่ระบุ, `false` = ไม่ทำพื้นโปร่งใส | `"auto"` |
| `anims` | ระบุรายชื่อไฟล์ของแต่ละท่าเอง (ถ้าระบุท่าไหน จะไม่ค้นหาชื่อมาตรฐานของท่านั้น) | ค้นหาตามชื่อมาตรฐานด้านบน |

## วิธีเซฟภาพจากตัวจำลองตัวละคร (ratemyserver.net)

1. เปิด https://ro-character-simulator.ratemyserver.net/
2. แท็บ **Trans** → เลือกอาชีพ (Lord Knight, Sniper, Stalker, High Wizard, Professor, Whitesmith, High Priest) เลือกเพศ/ทรงผม/หมวกตามชอบ
3. ตั้ง **Direction** ให้หันลงซ้ายหรือลงขวา (เข้ากับมุมมองไอโซเมตริกของแผนที่) และ **Action**:
   - ยืน (Stand/Idle) → เซฟเป็น `idle.png`
   - โจมตี/ร่ายสกิล แต่ละเฟรม (เปลี่ยน frame) → เซฟเป็น `work-1.png`, `work-2.png`, …
   - นั่ง (Sit) → เซฟเป็น `sit.png`
4. **คลิกขวาที่รูปตัวละคร → Save image as…** ลงโฟลเดอร์ของอาชีพนั้น
5. รีเฟรชหน้า dashboard — ถ้าโหลดสำเร็จจะมีข้อความ `[scene] ใช้สไปรต์ PNG ของ <jobId>` ใน console ของเบราว์เซอร์ และรูปในแผงรายชื่อซ้ายจะเปลี่ยนตาม

ถ้าภาพที่เซฟมีพื้นหลังสี (เช่น ขาว/ฟ้า) ไม่ต้องลบเอง ระบบทำให้โปร่งใสให้ แต่ถ้าเสื้อผ้าตัวละครสีเดียวกับพื้นพอดี ให้ตั้ง `transparent` เป็นสีพื้นที่แน่นอน หรือเปลี่ยนสีพื้นในตัวจำลองก่อนเซฟ

## ฉากหลังแบบภาพ: ใช้ภาพแผนที่จริงแทนฉากที่วาด

วางภาพแผนที่ไว้ที่ `public/sprites/png/map/morroc.png` (หรือ `.jpg`) แล้วรีเฟรช ระบบจะใช้ภาพนั้นเป็นพื้นฉากทั้งหมดแทนกระเบื้อง/อาคารที่วาดในโค้ด
ตัวละคร ป้ายชื่อ กล่องข้อความ ม้วนกระดาษบิน และเอฟเฟกต์ยังทำงานเหมือนเดิม (ไม่วาด "สถานี" หลังตัวละคร เพราะภาพมีอาคารอยู่แล้ว)
ลบไฟล์ภาพออก = กลับไปใช้ฉากวาดเดิม

### manifest.json ของแผนที่ (`public/sprites/png/map/manifest.json`)

```json
{
  "image": "morroc.png",
  "fit": "contain",
  "charScale": 1,
  "spots": {
    "lord-knight": [0.50, 0.56],
    "sniper":      [0.30, 0.80],
    "stalker":     [0.40, 0.86],
    "high-wizard": [0.78, 0.36],
    "professor":   [0.76, 0.70],
    "whitesmith":  [0.22, 0.40],
    "high-priest": [0.52, 0.24]
  },
  "zones": {
    "plaza":   [0.50, 0.47],
    "gate":    [0.33, 0.92],
    "tower":   [0.80, 0.28],
    "library": [0.78, 0.62],
    "forge":   [0.20, 0.32],
    "temple":  [0.52, 0.16]
  },
  "spare": [[0.2, 0.95], [0.6, 0.95], [0.9, 0.9]]
}
```

| ฟิลด์ | ความหมาย |
|---|---|
| `image` | ชื่อไฟล์ภาพในโฟลเดอร์ `map/` (ถ้าไม่ระบุ จะลอง `morroc.png`, `morroc.jpg`, `map.png`, `map.jpg`) |
| `fit` | `contain` = เห็นทั้งภาพ (ค่าเริ่มต้น), `cover` = ขยายเต็มเวทีแล้วตัดขอบ |
| `charScale` | ตัวคูณขนาดตัวละครบนภาพนี้ (1 = ปกติ, 1.3 = ใหญ่ขึ้น 30%) |
| `spots` | จุดยืนของแต่ละอาชีพเป็น **สัดส่วนของภาพ** `[x, y]` ค่า 0–1 (0,0 = มุมซ้ายบน, 1,1 = มุมขวาล่าง) จุด = ตำแหน่งเท้า |
| `zones` | ตำแหน่งป้ายชื่อโซน (ใช้ชื่อโซนเดิม: plaza, gate, tower, library, forge, temple, oasis) ไม่ระบุโซนไหน = ไม่วาดป้ายนั้น |
| `spare` | จุดสำรองสำหรับคนที่ไม่มีใน `spots` |

### โหมดช่วยปรับพิกัด (กด D)

1. คลิกที่แผนที่ 1 ครั้งให้โฟกัส แล้ว **กดปุ่ม D** → ขึ้นเส้นไขว้ตามเมาส์พร้อมพิกัด `[x, y]` และจุดยืนของทุกคน
2. เลื่อนเมาส์ไปยังจุดที่อยากให้ตัวละครยืน (ตำแหน่งเท้า) แล้ว **คลิก** → พิกัดถูกคัดลอกเข้าคลิปบอร์ด
3. วางลงใน `manifest.json` ที่ `spots` ของอาชีพนั้น → บันทึก → รีเฟรชหน้าเว็บ
4. กด D อีกครั้งเพื่อปิดโหมด (ระหว่างเปิดโหมด การคลิกจะไม่เปิดแผงรายละเอียด)

## ข้อควรระวังเรื่องลิขสิทธิ์

ภาพจากตัวจำลองเป็นสไปรต์ของเกม Ragnarok Online (ลิขสิทธิ์ Gravity Co., Ltd.) เหมาะกับการใช้ **ภายใน/ต้นแบบส่วนตัว** เท่านั้น
ถ้าจะนำระบบไปใช้ในองค์กร เผยแพร่ หรือขาย ให้กลับไปใช้สไปรต์ที่วาดเอง (`public/sprites/*.js`) หรือจัดหาภาพที่มีสิทธิ์ใช้งาน — เพียงลบโฟลเดอร์ของอาชีพนั้นออก ระบบจะกลับไปใช้ภาพเดิมทันที
